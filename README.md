## About the course

The course focuses on the particular challenges and constraints of smaller projects: setting clear objectives, planning scope, schedule and budget, allocating resources, tracking progress, managing risk and stakeholders, and closing the project cleanly. All activities use one connected Singapore SME case, the HarbourHub Fresh Click & Collect Pilot.

## Learning outcomes

- **LO1:** Develop project scope and team to initiate the facilitation of a small project.
- **LO2:** Develop a project plan based on the project scope.
- **LO3:** Utilise appropriate methods and tools to track and drive a project.
- **LO4:** Identify and manage project risks.
- **LO5:** Collaborate with project stakeholders.
- **LO6:** Deploy resources for the project.
- **LO7:** Track project deliverables and correct misalignment.

## Topics covered

1. Initiation of a Project
2. Develop a Project Plan
3. Apply Methods and Tools to Drive a Project
4. Manage Project Risk
5. Collaborate with Stakeholders
6. Deploy Resources
7. Track Project Deliverables and Correct Misalignments
