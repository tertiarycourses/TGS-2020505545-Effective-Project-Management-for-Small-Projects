# Effective Project Management for Small Projects

WSQ courseware for **TGS-2020505545**, covering practical initiation, integrated planning, project tools, risk, stakeholder engagement, resources, control and closure for small projects.

![Courseware cover](screenshot.png)

## Current release

- Version: **v18.0**
- Release date: **19 August 2026**
- Duration: **2 days / 16 training hours**
- TSC: **Project Management — ICT-PMT-3026-1.1**
- Learning outcomes: **LO1–LO7**

## Package contents

- A 102-slide visual, concept-led trainer deck in editable PowerPoint and PDF formats.
- Learner Guide and Lesson Plan in editable DOCX and PDF formats.
- Seven connected, self-contained activity packs based on the HarbourHub Fresh Click & Collect Pilot.
- Editable project tools for charters, WBS, requirements, schedules, budgets, quality, risk, stakeholders, RACI, resources, Kanban, earned value and retrospectives.
- Printable worksheets, datasets, evidence requirements and acceptance criteria.

## Repository structure

```text
courseware/   Current PPTX, PDF, Learner Guide and Lesson Plan
activities/   Seven learner-facing activity packs and editable tools
README.md     Release overview
```

Detailed procedures are intentionally kept in the Learner Guide and activity packs. Slides focus on concepts, decision frameworks and visual explanation.

## Source alignment

The release retains the seven-topic syllabus and assessment method stated in the v17 master trainer deck. Content was strengthened using the supplied Agile Project Management and PMP reference decks while remaining scoped to small-project application.

## Assessment boundary

Assessment papers and answer keys are not published in this public repository. Assessment instruments remain controlled trainer materials and must be verified against the authenticated LMS-TMS source before revision.
